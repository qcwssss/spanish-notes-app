# 云端 TTS 付费策略草案（先记录，不实施）

## 背景
当前语音播放主要依赖浏览器 `speechSynthesis`。

问题：
- 移动端可选语音较少，体验不稳定
- 若接入云端 TTS，会产生真实成本

结论：
- 云端 TTS 不适合对所有用户默认开放
- 需要作为付费能力（或限额能力）进行控制

---

## 产品决策（当前共识）

1. **暂不立即开发云端 TTS**（先文档化）
2. **未来若接入云端 TTS，默认走分层策略**：
   - 免费用户：仅浏览器本地 TTS
   - 付费用户（Pro）：开启云端高质量语音
3. **避免将非官方 Edge TTS 作为生产主链路**
   - 可做调研/实验，不作为核心依赖

---

## 功能分层建议

### 免费层（Free）
- 使用浏览器本地语音
- 不产生云端 TTS 成本
- 当本地语音不足时给出引导文案（升级可用高质量语音）

### 付费层（Pro）
- 开启云端 TTS（跨设备稳定）
- 可提供更多音色和更自然发音
- 适合移动端和多语言学习场景

---

## 成本保护策略（未来必须做）

1. **每日字符上限**（按套餐）
2. **速率限制（Rate Limit）**
3. **缓存策略**（相同文本重复播放尽量复用音频）
4. **异常保护**（服务商故障时自动回退浏览器本地 TTS）

---

## 供应商方向（先结论）

- 生产优先考虑：官方服务（Azure / AWS / Google / OpenAI / ElevenLabs）
- 非官方 `edge-tts`：低成本但有稳定性与合规风险，不建议作为主方案
