# Shared Links 入口优化计划

## 背景
当前分享能力已经具备，但用户反馈“已分享链接管理入口不容易快速找到”。

目标是在不打扰主导航的前提下，提供一个低干扰但可发现的入口，帮助用户快速进入“分享链接管理”。

## 本次范围（仅规划，不改代码）
- 新增一个轻量入口，跳转到分享管理页面（后续路由可用 `/shares`）。
- 不调整主侧边栏的一级导航结构（如 All Notes/Favorites 等）。
- 不修改当前分享逻辑（创建、复制、撤销）。

## 交互决策（已确认）
1. 入口放在侧边栏左下信息区。
2. 优先放置在“Language”这一行右侧空白位置。
3. 入口样式为小图标链接（如 `🔗` / `Link` 图标），保持低视觉权重。
4. 点击后跳转到“分享管理”页面。

## 设计要求
- **不喧宾夺主**：入口应为次要视觉层级，不与主操作抢注意力。
- **可发现性**：鼠标悬停时显示 tooltip（如 `Manage shared links`）。
- **一致性**：颜色、圆角、间距与现有信息区风格一致。
- **可访问性**：
  - 提供 `aria-label`
  - 可键盘聚焦
  - 有可见焦点样式

## 布局草图（Desktop）
```text
Settings
Language: Spanish                      [🔗]
Storage: 68%
```

## 布局草图（Mobile）
```text
Settings
Language: Spanish               [🔗 Shared]
Storage: 68%
```

## 实施拆分（后续开发）
1. 在信息区组件中增加“分享管理入口”按钮。
2. 为入口补充 i18n 文案（中英文）。
3. 新增目标页面路由占位（`/shares`）或先接入已有页面。
4. 增加基础测试：
   - 渲染入口
   - 点击可跳转
   - aria-label 存在

## 验收标准
- 用户可在 2 秒内在左下信息区发现入口。
- 点击入口可成功进入分享管理页。
- 侧边栏主导航不受影响。
- 视觉风格与现有信息区一致，无突兀感。

## 风险与备注
- 若“Language 行”在某些屏幕宽度过窄，入口可能拥挤。
  - 兜底：移动端显示为 `🔗 Shared` 文案按钮，避免纯图标难识别。
- 后续若确认入口发现性不足，可在 Settings 页面追加二级入口作为备选路径。
