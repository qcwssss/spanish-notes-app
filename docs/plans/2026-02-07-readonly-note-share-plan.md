# 只读笔记分享方案（V1）

## 一、目标
支持用户把单条笔记通过链接分享给他人；被分享者只能只读查看，并可在自己浏览器中点击文本进行发音播放（TTS）。

## 进度更新（2026-02-08）

### 已完成
- 只读分享主流程已上线：生成链接、复制链接、撤销分享、公开访问 `/share/[token]`。
- 分享页已接入 `NotePlayer`，访问者可只读查看并点击发音。
- 分享权限规则已生效：访问者不能编辑/删除/收藏。
- 撤销后再分享同一笔记时，复用同一个 token。
- 无效链接展示业务宣传页（统一不可用文案 + CTA）。
- Cloudflare Pages 构建已通过，测试已通过。

### 待做（可选增强）

## 二、产品规则（已确认）
- 分享链接访问者仅有只读权限。
- 访问者可以：
  - 查看笔记标题与内容
  - 点击文本触发发音播放（浏览器 TTS）
- 访问者不可以：
  - 编辑
  - 删除
  - 收藏
  - 新建/移动笔记
- 分享链接默认长期有效（不设置过期时间）。
- 仅笔记作者可撤销分享。
- 若笔记被删除，分享链接自动失效。
- 若作者撤销后再次分享同一笔记，沿用原 token（仅恢复 `is_active=true`，不生成新 token）。
- 作者更新笔记后，分享页在访问者“刷新页面后”展示最新内容（弱实时）。
- 作者在笔记编辑页内管理分享（分享/复制/撤销），V1 不单独新增“分享管理页面”。
- 分享页发音语言跟随作者的 `target_language`；访问者不能切换语言种类，只能在该语言下选择可用语音。
- 分享链接生成规则：`{publicAppUrl}/share/{token}`，token 放在 path，不放 query。

## 三、V1 范围
- 增加“生成分享链接”能力。
- 增加“撤销分享”能力。
- 增加公开只读页面：`/share/[token]`。
- 复用现有 `NotePlayer`，保证分享页可点读发音。
- 补齐分享相关 i18n 文案（中英文）。

## 四、V1 不做
- 自定义过期时间
- 一条笔记多个并行有效链接
- 链接密码保护
- 分享访问统计（浏览量等）
- 独立的分享管理页
- 页面不刷新自动同步内容（WebSocket 强实时）

## 五、用户流程

### 1) 作者侧
1. 作者打开一条笔记
2. 点击“分享”
3. 系统生成或返回该笔记分享链接
4. 作者一键复制链接（toast 提示）
5. 作者可点击“撤销分享”，链接立即失效

### 2) 访问者侧
1. 打开 `/share/[token]`
2. 若链接有效：进入只读页面，查看内容并可点读发音
3. 作者后续修改内容时，访问者刷新页面后可看到最新内容
4. 若链接无效/已撤销/笔记已删除：显示业务宣传页（统一“分享不可用”文案 + CTA）

### 3) 更新提醒（可选，V1.1）
1. 分享页在“用户回到页面”时检查笔记版本（如 `updated_at`）
2. 触发时机：`visibilitychange`、`focus`、`online`、`pageshow`
3. 发现更新时提示“笔记已更新，点击刷新查看最新内容”
4. 访问者点击后刷新页面获取最新内容

## 六、技术方案

### 1) 数据模型（建议）
新增表：`note_shares`
- `id` uuid 主键
- `note_id` uuid 非空（关联 `notes.id`）
- `owner_id` uuid 非空（关联 `auth.users.id`）
- `token` text 唯一非空（高随机、不可猜）
- `is_active` boolean 非空默认 `true`
- `created_at` timestamptz 默认 `now()`

建议索引/约束：
- `token` 唯一索引
- `owner_id` 索引
- 每条笔记仅一条分享记录（可通过唯一约束或逻辑控制）

### 2) 后端能力
- `createOrGetNoteShare(noteId)`
  - 需登录
  - 校验笔记归属
  - 返回已存在分享或新建分享 token
- `revokeNoteShare(noteId)`
  - 需登录
  - 校验笔记归属
  - 设置 `is_active = false`
- `getSharedNoteByToken(token)`
  - 公开读取
  - 校验 token 存在且有效
  - 仅返回展示所需字段（title/content/targetLanguage 等）

### 3) 页面路由
- 新增页面：`src/app/share/[token]/page.tsx`
- 该页面公开可访问
- 服务端按 token 获取分享数据
- 页面仅展示只读内容，不渲染任何写操作按钮

### 4) 作者侧管理入口
- 管理入口放在笔记编辑页内（不新增管理页）
- 采用 FAB Dock（右下角悬浮 icon-only）
- 一级动作：编辑（`✎`）+ 更多（`⋯`）
- 更多菜单：按状态显示分享/复制/撤销/删除

## 七、安全与权限
- token 必须高熵随机，避免被枚举
- 分享查询接口最小化返回字段，避免信息泄露
- 所有写操作必须做“登录 + 所有权”校验
- 撤销或笔记删除后，不得继续返回原文内容

## 九、测试计划

### 1) 逻辑测试
- 拥有者可创建/获取分享链接
- 非拥有者不能创建/撤销分享
- 已撤销 token 返回不可用
- 笔记删除后 token 返回不可用

### 2) 页面测试
- 分享页不出现编辑/删除/收藏按钮
- 分享页可正常渲染内容
- 可触发发音逻辑（mock `speechSynthesis`）

## 十、验收标准
- 作者可生成并复制分享链接
- 未登录访问者可打开并只读查看笔记
- 访问者可点击文本进行发音
- 作者撤销后，旧链接立即失效
- 笔记删除后，链接失效
- 分享页无任何写权限入口
