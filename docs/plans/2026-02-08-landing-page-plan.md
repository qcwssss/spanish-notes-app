## 功能亮点（需明确覆盖）

Landing 文案中需要覆盖你提到的核心功能，避免只讲“发音”而遗漏管理能力：

1. **笔记编辑能力**
   - 创建、编辑、删除笔记
2. **文件夹组织能力**
   - 支持文件夹分组与管理（创建/重命名/删除）
   - 支持笔记在文件夹之间移动
3. **收藏能力**
   - 笔记可收藏
   - 有独立收藏视图（Favorites）
4. **发音学习能力**
   - 点击文本即可听发音
5. **主题模式**
   - 支持浅色 / 深色视觉模式
6. **语言学习设置（产品规则要写清）**
   - 支持多语言目标语言选择
   - 在设置页进行选择
   - 免费用户仅可设置一次
   - 需要付费（Pro）才可修改已设置的目标语言

---

## 关键交互说明（Landing 文案应体现）

针对“可用性”要明确告诉用户怎么操作，避免只讲能力不讲用法：

1. **移动笔记到其他文件夹**
   - 支持将笔记从一个文件夹移动到另一个文件夹
2. **修改文件夹名称（两种方式）**
   - 双击文件夹名称直接重命名
   - 点击文件夹的 `...` 菜单，选择“修改/重命名”

建议在 Landing 的「How it works」或「Pro tips」区块放一行简短提示：
- “Tip: Double-click a folder name to rename, or use the `...` menu for more actions.”

## 视觉风格建议
- 风格：简洁、学习感、轻科技（不过度炫技）
- 颜色：以蓝/青为强调色，避免高饱和大面积撞色
- 图形：可用轻插画/图标，减少复杂装饰
- 动效：只做轻入场（首屏），避免持续动画干扰阅读

## FAQ 必须包含的规则说明（建议）

1. 免费用户可以改学习语言吗？
   - 免费用户仅可设置一次目标语言；若需修改，需升级到 Pro。
2. 可以整理很多笔记吗？
   - 可以，通过文件夹组织并支持收藏。
3. 分享出去的人能修改吗？
   - 不能，分享链接是只读模式。
